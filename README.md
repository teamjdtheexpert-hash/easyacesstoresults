# Zorax Marketing

Premium artist-growth website built with Next.js, React, TypeScript, Tailwind CSS and Framer Motion.

## Development

```bash
npm install
npm run dev
npm run build
```

## Content

Editable services, artist placeholders, case studies, impact metrics, program and process data live in `lib/content.ts`.

## Production notes

- The application form is currently UI-only and should be connected to Zorax's preferred CRM/form endpoint.
- Artist imagery, social links and case-study metrics intentionally use placeholders until verified assets/data are supplied.
- Canonical domain and SEO metadata target https://wearezorax.com.
